## 🔬 LLM Evaluation

I have a strong interest in **LLM response evaluation and model behavior analysis**.

A typical evaluation workflow I work with is:

```text
Prompt
   ↓
LLM Response
   ↓
Evaluation Criteria
   ↓
Rubric
   ↓
Scoring
   ↓
Failure Analysis
   ↓
Improved Prompt / Model / Workflow
```

Example evaluation dimensions:

| Criterion       | Purpose                                   |
| --------------- | ----------------------------------------- |
| Correctness     | Is the answer factually correct?          |
| Relevance       | Does it address the user's request?       |
| Groundedness    | Is it supported by available information? |
| Completeness    | Does it satisfy the complete request?     |
| Safety          | Does it follow system constraints?        |
| Professionalism | Is the response appropriate and clear?    |
